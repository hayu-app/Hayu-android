# Patch scripts (arsip)

Semua patch di sini **sudah terapkan** ke kode di `app/src/main/`.
Disimpan hanya sebagai riwayat; jangan dijalankan ulang karena akan menimpa
perubahan yang lebih baru (mis. `CoinAdminActivity`, `RoleManagerActivity`, `VipActivity`).
